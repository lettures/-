# 磁盘地图 DiskMap

**用一张图，看清 Mac 的磁盘空间去了哪里。**

磁盘地图是一款中文界面的 macOS 磁盘空间分析工具。它把文件和文件夹的占用情况呈现为矩形树图，帮助你找到占空间的大文件、查看目录内部构成，并检查重复文件及常见命令行工具的安装与缓存位置。

## 可以用它做什么

- **找出空间大户**：扫描文件夹或磁盘，用树图和大文件排行查看主要占用来源。
- **看清密集的小项目**：将过小图块合并成“过小项目”区域，双击单独展开，并通过列表继续查看全部项目。
- **集中查看关心的区域**：按住 Command 多选图块，在独立视图中一起展示；也可逐层进入目录。
- **按类型分析文件**：筛选视频、图片、文档、压缩包、应用等类型，配合文件详情和 Finder 定位进行整理。
- **检查重复内容**：按大小分组、分块哈希预筛，再进行完整哈希和逐字节校验；结果供查看与定位，不自动删除。
- **比较目录变化**：保存目录级扫描快照，比较不同时间的逻辑大小变化。
- **检查终端工具与缓存**：独立查看常见 Homebrew、npm、pipx、Cargo 等位置。该功能目前为只读预览，不将缓存直接认定为卸载残留。
- **辅助清理文件**：完整扫描后，可明确确认将选中的普通文件移入 macOS 系统废纸篓；操作前重检文件身份和保护范围，不提供永久删除。

## 如何使用

1. 打开应用，选择文件夹，或从快捷扫描入口选择目录或磁盘。
2. 扫描期间即可查看渐进结果，也可以随时取消。
3. 单击图块查看详情，双击目录深入；用“上一级”返回。
4. 遇到密集小图块，可展开“过小项目”区域，或右键选择“单独展示此处全部项目”。
5. 使用 Finder 定位核对文件；如需清理，确认路径后再移入废纸篓。

## 如何理解占用数字

树图与排行以**磁盘占用**为主，文件详情同时保留**逻辑大小**，避免把稀疏虚拟磁盘声明的大容量误认为真实占用。

磁盘占用采用已分配块统计；APFS 克隆及硬链接可能共享空间，因此不等于独占容量或删除后可释放空间。重复检测和历史快照仍采用逻辑大小。移入废纸篓不会立即释放空间。
