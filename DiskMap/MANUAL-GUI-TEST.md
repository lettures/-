# 可重复人工长期验收

使用自建可丢弃测试目录，不对重要文件操作。

1. 创建大量文件及深层子目录，连续扫描/取消/换目录至少一小时；期间缩放、切换排行、调整窗口尺寸，记录活动监视器内存及卡顿时间。
2. 扫描后替换同名同大小文件，再尝试移入废纸篓，应拒绝；重新扫描后打开确认框，再改写内容，确认仍应拒绝。
3. 创建硬链接、指向 /System 的符号链接和无权限子目录；链接不可清理，权限中文提示，硬链接只移动选中路径。确认框回车应取消。切勿清空废纸篓。
4. 重复检测开始后关闭窗口，再次扫描，旧结果不可回填；重复独立副本应经完整验证显示，硬链接不作为额外副本。
5. 保存及切换历史，达到 30 份应拒绝新增；只把自建快照移入废纸篓，核实源文件不变。
6. 复验悬停、所有类型、嵌套层数、树图双击导航及 Finder；记录系统版本、时长、进程内存和失败步骤。

上述一小时及整夜流程本轮未完成，不应据此标为通过。
