# DiskMap V0.6.0 实测报告

2026-11-02，当前 Apple Silicon Mac，macOS 27.2，版本 0.6.0 (9)。延续原工程。

## 已通过

- Release 编译及 Bundle 校验：可执行文件、arm64、版本、部署目标和本地 ad-hoc 签名。
- 核心自动回归：扫描、渐进预览、筛选、排行、导航父链、权限、符号链接循环、硬链接及原生 APFS clonefile。空间始终采用逻辑字节，不宣称精确可释放容量。
- 安全自动回归：扫描后同大小文件替换、确认后内容变化、祖先目录替换均拒绝；系统保护、根目录、范围外和链接拒绝。没有永久删除路径。
- 重复文件：分块预筛冲突由完整校验拒绝；完整哈希后逐字节比较、读取字节数及身份校验；硬链接不算额外副本。
- 快照：30 份配额拒绝第 31 份且保留旧文件，损坏及负值记录跳过，加载预算及 UUID 文件名校验通过。
- 模型三分钟循环 304 次，含扫描、重复检测、快照保存/读取/对比/关闭和目录切换，274 次达到配额后拒绝新增；旧节点弱引用释放断言通过。另有两次扫描取消重启和三次重复检测立即关闭。采样 RSS 最大 14896 KiB，退出码 0。这是模型测试，不是 GUI 长时间验收。

## 原生 GUI 实际执行

- 启动、文件夹选择、真实目录扫描、渐进树图及缩放；最终大小排序构建百万目录 1,000,001 项，12.8 秒，RSS 采样最大 406192 KiB（396.7 MiB）。排序修复前 19.1 秒，未隐藏该回退，详见 PERFORMANCE.md。
- 另一轮扫描在约 37 万项时点击取消，约 914 ms 后观察到退出扫描状态，含工具开销；保留部分结果与中文取消提示。随后成功切回小目录扫描。
- 无权限目录显示中文错误；双击子目录进入、返回上级、图片筛选、文件详情和 Finder 定位真实图片文件通过。
- 扫描后同名替换及确认框打开期间同大小改写，均拒绝清理且文件保留。普通测试文件明确确认后移入系统废纸篓并自动重扫。
- 最终大小排序构建再次测试回车默认取消；明确确认后只移走 5000 字节测试路径，硬链接另一条仍存在，自动重扫 12 项变 11 项。系统符号链接被拒绝，无移动确认。
- 重复结果显示一组两个 50000 字节文件且标明逐字节验证；关闭释放结果。新建快照保存后确认移入废纸篓，历史 3 份变 2 份，原扫描文件和已有旧快照保留。

## 未验证与实际限制

整夜 GUI 稳定性、所有类型及悬停逐项复验、断开外置卷/网络卷失败恢复、百万候选完整重复检测、macOS 14 实机运行未验证。未做 Instruments 分配归因，不能认定没有泄漏。切回小目录后 GUI 单次 RSS 仍约 311.6 MiB，不能承诺所有缓存立即归还系统。

路径检查与系统废纸篓调用之间不是原子事务，不能保证抵御恶意并发文件系统替换。扫描也不是一致性文件系统快照。APFS 共享块及独占物理空间未精确测量。

最后一次变更仅完善符号链接缺少身份时的中文提示，完整自动回归及编译重跑；上述 GUI 操作在该文字调整前执行，不冒称最终字面构建重复完成全部 GUI。未用编译成功代替运行验证。

结论：关键日常功能和清理防护有真实运行证据，可用于当前 Mac 本地使用；长时间稳定性仍需持续观察。原始数据见 Tests/Results-v060。测试文件留在系统废纸篓，可恢复，未清空废纸篓。
