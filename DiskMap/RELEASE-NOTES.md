# DiskMap V0.6.0 本地稳定性改进版

延续原 SwiftUI + AppKit 工程，版本 0.6.0 (9)。用于当前 Mac 本地使用，无 Developer ID、无公证；保留本地 ad-hoc 签名。

- 清理前对照扫描身份，明确确认后再次校验文件及祖先目录，拒绝变化、链接、保护区域和非普通文件。只调用系统废纸篓，不提供永久删除。
- 重复检测强化完整读取、身份及字节数核验；关闭窗口取消任务并释放结果。结果只查看和定位。
- 完成任务后释放任务引用，切换扫描退役旧树和重复结果，关闭历史释放记录；新增连续循环与取消重启测试。
- 历史限 30 份 / 64 MiB，单份 4 MiB，加载合计 8 MiB。满额拒绝新增，支持明确确认后移入单份快照 JSON，损坏记录跳过提示。
- 大量同大小文件按大小稳定排序，避免无必要的名称排序。最终 GUI 百万文件 12.8 秒，RSS 采样最大约 397 MiB。

保留中文、快捷扫描、渐进预览、嵌套树图、缩放、悬停、目录导航、筛选、排行、取消和 Finder。已验证范围与限制见 TEST-REPORT.md；“稳定性改进”不代表通过整夜压力测试或所有 macOS 版本认证。
