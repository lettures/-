# 空间统计行为

V0.6.0 延续逻辑大小口径，不将其称为可释放空间。当前工作卷通过 statfs 确认为 apfs；原生 clonefile 在测试临时目录成功执行。

| 情况 | 当前统计 | 本轮验证 |
|---|---|---|
| 普通文件 | 文件逻辑字节数 | 通过 |
| 同一文件的硬链接 | 每个路径均计入，可能重复 | 原文件 8192 + 硬链接 8192 = 16384，通过 |
| APFS 克隆 | 每个路径的逻辑大小均计入 | 增加 8192 字节原生克隆后总计 24576，通过 |
| 符号链接 | 不跟随，计零 | 文件链接及目录循环测试通过 |
| 权限拒绝 | 列中文错误，跳过不可读内容 | 底层及原生界面通过 |

APFS 共享块的独占归属、克隆写入后的块分裂、快照占用、压缩和稀疏文件的物理占用未精确计算。成功创建克隆不代表测得它独占多少磁盘块；硬链接的重复计数是已知统计口径。本轮未改变这些行为，以免把近似物理值混入逻辑总量。扫描不是文件系统快照，文件变化可能导致错误或不一致；界面错误和部分结果提示需要结合查看。

移入废纸篓只改变路径位置；硬链接其他路径和废纸篓中的数据仍可占用物理空间。重复结果与历史差值均采用逻辑大小，不等同于可回收容量。目录快照存在层级包含关系，各行不可累加。

本轮新增扫描中自建文件移除/新增回归，无崩溃；扫描后同路径替换和确认期间同大小内容变化均在真实 GUI 中被拒绝清理。扫描时间戳不是一致性快照，成功扫描仍只代表观察期间的逻辑汇总，不能承诺正在变化的目录具有某一瞬间的精确总量。重复检测需完整哈希及逐字节相同、读取字节数和身份均稳定，才报告重复；其后内容仍可能变化。
